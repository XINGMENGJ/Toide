# 当前功能说明

## 项目工作区

Toide 会把一个本地目录作为工作区。当前示例工作区位于 `examples/default-workspace`，程序启动时会自动打开它。

## 文件浏览

左侧文件树使用 Qt 的 `QFileSystemModel` 显示目录结构。双击普通文件会在编辑器区域打开。

## 编辑器

当前编辑器基于 `QPlainTextEdit`，支持：

- 多标签页。
- 重复打开同一文件时复用已有标签。
- 脏状态标记。
- 保存当前文件。

## 任务运行

底部 Tasks 面板读取 `.toide/tasks.json`。当前支持：

- 显示任务列表。
- 执行当前选中的任务。
- 通过 `Build Example` 自动加载 Qt 6.7 MinGW 环境并编译示例 C++ 文件。
- 通过 `Run Example` 运行编译产物。
- 在编译产物缺失时给出需要先构建的提示。
- 通过 `Build Diagnostics Demo` 故意触发编译错误，验证诊断输出。
- 显示标准输出、标准错误和退出码。
